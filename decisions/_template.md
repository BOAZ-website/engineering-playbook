# NNNN 결정 제목

결정 기록 형식은 MADR을 차용함

## 결정 기록을 쓰지 않아도 되는 경우

- 작고 위험이 낮거나 임시인 결정
- 이미 `conventions/`에 있는 규칙을 따르는 결정

## 번복할 때

- 기존 기록을 고치지 않고 새 기록을 씀
- 기존 기록의 상태를 "대체됨(→ 새 번호)"으로 바꿈

## 상태

| 항목 | 값 |
|---|---|
| 상태 | 제안 / 채택 / 거부 / 폐기 / 대체됨(→ 0000) |
| 결정일 | YYYY-MM-DD |
| 결정자(역할) | 역할명 |
| 의견을 준 역할 | 역할명 |

- 채택된 기록은 본문을 수정하지 않음. 바뀌면 새 기록을 만들고 상태만 "대체됨"으로 변경

## 배경

- 해결할 문제와 현재 상황. 3줄 이내

## 선택지

| 선택지 | 내용 | 장점 | 단점 | 채택 | 탈락 사유 |
|---|---|---|---|---|---|
| A | | | | | |
| B | | | | | |

- 이전에 시도한 것: 같은 문제에 앞서 쓴 방법과 결과. 없으면 "없음"

## 결정

- 단정형 1문장

## 근거
