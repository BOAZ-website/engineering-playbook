# [Product 이름]

Product 문서 공통 목차. 복사해 `products/<이름>.md`로 사용. 저장소 README에 있는 내용은 복사하지 않고 경로로 가리킴

## 메타

| 항목 | 내용 |
|---|---|
| 담당 역할 | PM / Product Engineer. 실명 금지 |
| 상태 | 운영 중 / 개발 중 / 백엔드 미연동 등. 기준일(절대 날짜) 포함 |
| 저장소 | GitHub 저장소 링크 |
| 사용자 | 누가 쓰는지 |
| 의존하는 Product | 이 Product가 동작하려면 필요한 Product |
| 제공하는 API·산출물 | 다른 Product가 가져다 쓰는 것 |
| 사용하는 API·산출물 | 다른 Product에서 가져다 쓰는 것 |
| 관련 계약 문서 | `contracts/*` 경로 |

## Product 소개

- 이 Product가 무엇이고 왜 있는지 1~2줄
- 누가 어떤 기능·화면을 쓰는지(주요 기능 목록, 필요하면 표)
- 다른 Product와 어떻게 연결되는지(데이터·호출 흐름)
- 모집 시즌 등 운영상 중요한 시기
- 저장소에서 확인한 사실만 적음. 확인하지 못하면 `[확인 필요: ...]`. 3~10줄
